IberoLab

Privacidad

IberoLab está diseñado como una web estática y transparente. La adaptación de palabras y las pruebas técnicas se ejecutan localmente en el navegador.

Datos de uso

IberoLab no incorpora analítica, publicidad, cuentas de usuario, cookies de seguimiento ni formularios propios. Las palabras escritas en el demostrador no se envían a un servidor de IberoLab.

Audio en el dispositivo

IberoLab no envía a sus servidores el texto ni el audio de ninguna función sonora. La voz fluida y «Escuchar entrada en español» solicitan el sistema de voz administrado por el navegador o dispositivo; su disponibilidad, la posible descarga de voces y su funcionamiento interno dependen de la plataforma. El modo técnico calcula íntegramente sus muestras mediante JavaScript en el navegador.

Enlaces compartibles

Cuando se utiliza la función de compartir, la entrada se incluye en el parámetro ?q= de la URL para que otra persona pueda abrir el mismo resultado. No uses información sensible o privada en enlaces que vayas a publicar.

Servicios externos

  • La web se aloja mediante GitHub Pages, sujeto a las políticas de GitHub.
  • Los enlaces a publicaciones, universidades o repositorios abren sitios externos.
  • El envío de sugerencias mediante GitHub Issues requiere una cuenta de GitHub.
  • El correo electrónico se procesa mediante el proveedor utilizado por quien escribe y por la cuenta del proyecto.

Contacto

Las dudas sobre privacidad pueden enviarse a iberolab.es@gmail.com o registrarse en el repositorio público.
