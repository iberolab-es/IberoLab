Formas ibéricas contrastadas

Primer paso verificable del proyecto: reconstruir lecturas documentadas antes de intentar adaptar palabras modernas por similitud fonética.

No es una traducción al idioma ibérico. La página representa una transliteración académica mediante formas gráficas normalizadas del signario ibérico nororiental dual. No pretende reproducir el alógrafo exacto de cada inscripción.
