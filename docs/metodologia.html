Una herramienta útil solo si explica qué está haciendo.

IberoLab distingue deliberadamente entre evidencia epigráfica, normalización gráfica y adaptación moderna. El objetivo no es aparentar una certeza inexistente, sino ofrecer resultados visuales comprensibles y trazables.

1. Corpus atestiguado

Incluye formas documentadas en publicaciones o registros institucionales. Cada entrada conserva contexto, segmentación, interpretación prudente y fuente.

2. Signos normalizados

Los SVG representan formas gráficas de referencia. No se presentan como facsímiles exactos de una inscripción concreta salvo que exista una variante explícitamente documentada.

3. Adaptación moderna

El conversor transforma nombres y frases breves mediante reglas fonéticas sencillas. Cuando un sonido moderno no encaja directamente, la aproximación se muestra al usuario.

4. Salida explicada

La herramienta ofrece signos, lectura técnica, avisos, enlace compartible y un historial exclusivamente local. Una entrada no admitida se bloquea sin producir signos parciales.

Lo que IberoLab no afirma

No traduce el español al idioma ibérico.

La adaptación moderna no demuestra que una persona ibérica hubiera escrito, entendido o pronunciado así la palabra original. Es una representación experimental sobre un signario histórico normalizado.

Trazabilidad técnica

Datos, licencias y pruebas abiertas.

El repositorio conserva corpus, inventarios, manifiestos de recursos, hashes, validadores y pruebas de navegador. Los cambios se integran mediante pull requests y regresión automatizada.

Identidad visual

Un signo-raíz contemporáneo.

El eje central representa memoria y continuidad; las ramas, transmisión y expansión del conocimiento; el círculo, preservación y unidad; el punto lateral, fuente y testimonio humano.

No es un signo ibérico arqueológico. Es un emblema moderno creado para identificar el proyecto.
