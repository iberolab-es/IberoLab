# Contribuir a IberoLab

Gracias por ayudar a mejorar IberoLab. El proyecto acepta aportaciones técnicas, lingüísticas, epigráficas, documentales y de accesibilidad.

## Antes de enviar una propuesta

1. Comprueba que no exista una issue equivalente.
2. Indica con precisión qué palabra, signo, variante o comportamiento estás analizando.
3. Separa claramente los datos documentados de las hipótesis personales.
4. Añade una referencia bibliográfica, catálogo, fotografía o enlace verificable cuando la propuesta dependa de evidencia externa.

## Tipos de aportación

- **Error técnico:** la web no responde, no renderiza o produce una salida incoherente.
- **Aportación documental:** nueva grafía, variante, valor propuesto o referencia.
- **Mejora metodológica:** cambio en normalización, adaptación o clasificación de confianza.
- **Mejora de producto:** interfaz, accesibilidad, exportación o experiencia de uso.

## Flujo de desarrollo

- Los cambios deben realizarse en una rama específica.
- Cada pull request debe resolver un objetivo concreto y limitado.
- Los cambios en datos lingüísticos deben incluir fuente y nivel de certeza.
- No se publicará como traducción literal ninguna salida que sea transliteración, adaptación o recreación.
- Las pruebas relevantes deben actualizarse junto con el código.

## Niveles de evidencia

Toda entrada futura de la base de signos deberá declarar uno de estos niveles:

- `documented`: documentado en una fuente identificable;
- `consensus`: interpretación ampliamente aceptada;
- `hypothesis`: hipótesis académica discutida;
- `experimental`: decisión propia del motor;
- `artistic`: recurso visual sin pretensión académica.

## Licencia de las contribuciones

Al enviar una contribución aceptas que se distribuya bajo la licencia Apache 2.0 del repositorio, salvo que se acuerde expresamente otra licencia para materiales de terceros.
